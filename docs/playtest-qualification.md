## Primary shipped gameplay promise (source behavior, not a roadmap)

Returning chunks receive **bounded Immersive Weathering catch-up**, not a replay of every missed random tick. `SamplerEvents` advances a dimension-level partitioned clear/rain and day/night clock during server level START ticks, records per-chunk snapshots in chunk NBT and queues previously initialized chunks on load. On the next tick, when enabled and the elapsed game time meets the configured minimum (default 100 ticks), `EndpointSampler` scans non-air sections and surface positions, samples probabilistic direct endpoints for weathering/rust and compatible Immersive Weathering growth rules, then invokes eligible actions only if the block state still matches. It skips sampling at random tick speed zero and avoids synchronously promoting unloaded FULL chunks for configurable growth; snow-icicle neighbors are guarded separately. Probability, density (default 1.0), and weather/rain partitioning affect the result; there is **no guarantee** that any particular block will visibly change on one reload. This mod is not an autonomous unloaded-world ticker, a new recipe tree, or proof of offline progress while the entire server is stopped. Sources: `SamplerEvents.java`, `ExposureSavedData.java`, `ChunkExposureData.java`, `EndpointSampler.java`, `ProbabilityMath.java`, `SamplerConfig.java`.
